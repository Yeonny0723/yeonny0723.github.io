# AI 엔지니어 경력기술서

Fasoo에서 기업용 보안 제품의 AI 기능과 운영 환경을 개발했습니다. Wrapsody는 기업 문서를 암호화하고 문서별 권한과 버전을 관리하는 서비스입니다. 사내 운영 환경에만 약 100만 건의 문서가 축적돼 있으며, 약 10여 고객사에 클라우드·온프레미스 형태로 제공하고 있습니다. 고객사별 서버 환경, 복잡한 문서 접근 권한, 문서 암·복호화와 종단 간 암호화를 고려해야 하며, 축적된 문서·권한 정보는 검색·요약·질의응답·문서 생성으로 확장할 수 있습니다.

Wrapsody eCo는 암호화된 문서를 웹·클라이언트·Outlook Add-in·모바일에서 사내외 구성원이 안전하게 공유하고 협업하는 서비스입니다. Mind-SAT은 약 41개 고객사가 사용하는 피싱 훈련·보안교육 SaaS로, 고객사별 훈련 결과·신고·교육 이력을 관리하고 퀴즈·동영상 교육을 제공합니다. 훈련 메일 분석, 공격 유형 파악, 메일 템플릿·퀴즈 생성에 AI를 활용합니다.

### Wrapsody 문서 생성 Agent | Fasoo | 2026~현재

- **역할·기술:** 메인 개발자로 Python 기반 문서 생성 Agent, 멀티턴 수정 흐름, 장기 작업 처리 구조와 Golden Dataset 평가 체계를 설계·구현했습니다.
- 템플릿과 원천 파일로 DOCX·PPTX·XLSX를 생성하고, 수정 요청에 따라 구조 추론·교체 영역 추론·연산자 변경 중 필요한 단계만 Agent가 선택하도록 구성했습니다. 5~10분이 걸리는 작업은 BackgroundTask·MySQL·전용 thread pool로 분리했습니다.
- **성과:** 사용자가 생성 화면을 벗어나도 작업이 계속되고, 재진입해 상태와 결과를 확인할 수 있게 했습니다. 채워지지 않거나 렌더링에 실패한 위치를 응답에 포함해 검토 범위를 줄였고, 모델·프롬프트 변경도 같은 평가 데이터로 비교할 수 있게 했습니다.

### Mind-SAT AI 콘텐츠 생성·서버 운영 | Fasoo | 2026

- **역할·기술:** 4인 개발팀에서 Python·OpenAI SDK·LangChain 기반 훈련 메일·보안 퀴즈 생성 백엔드를 개발하고, AI 서버 운영과 고가용성 인프라를 관리했습니다.
- 산업군·부서·직급·위협 수준·메일 유형을 생성 조건으로 나누고 OCR, 발신자 페르소나, 생성 결과 sanitize를 제품 흐름에 연결했습니다. 첨부파일과 이미지 처리로 메모리 사용량이 약 80%까지 오르던 1 OCPU·4GB 단일 서버의 병목도 함께 개선했습니다.
- **성과:** OCI Instance Pool·Private Load Balancer·이미지 인스턴스 빌더로 무중단 배포와 장애 복구가 가능한 인프라를 구성했습니다. 서버 한 대에 장애가 나도 신규 요청을 계속 처리하고 인스턴스를 자동 보충할 수 있게 했습니다.

### Wrapsody AI 검색·응답 평가 | Fasoo | 2026~현재

- **역할·기술:** 검색·평가 지원 역할로 Playwright를 이용한 반복 평가와 RAG·Text2SQL 품질 검증에 참여했습니다.
- 다국어·동의어·다의어 질의를 분석하고, 기대 문서와 본문 위치를 정의한 36개 평가셋을 구성했습니다.
- **성과:** Text2SQL, 문서 검색, 최종 응답을 단계별로 비교해 모델 변경 전후의 품질 차이와 실패 지점을 추적할 수 있게 했습니다.

### 디자인 시스템 MCP·관련 풀스택 개발 | Fasoo | 2024~2026

- **역할·기술:** React·TypeScript 기반 공통 UI 라이브러리와 제품 디자인 시스템을 구축하고, 컴포넌트·토큰·Storybook 예제를 조회하는 MCP 서버를 개발했습니다.
- 소스가 변경되면 조회 데이터도 자동 갱신되도록 구성해 AI 개발 도구가 실제 컴포넌트와 색상·아이콘 토큰을 확인한 뒤 코드를 작성하게 했습니다.
- **성과:** 공통 UI를 약 6개 사내 시스템에, 제품 디자인 시스템을 3개 제품에 적용했습니다. 프론트엔드 엔지니어 4명이 MCP를 사용하고 있으며, LLM Agent에 UI 개발을 맡긴 뒤 수동으로 검토·수정하는 시간을 기존의 1/5로 줄였습니다.

### TypeScript 기반 제품·플랫폼 개발 | Fasoo | 2024~2025

- **역할·기술:** React·TypeScript와 Node.js·Express를 사용해 여러 제품이 공통으로 사용하는 M365 Web Add-in 플랫폼을 개발했습니다.
- Mind-SAT 메일 신고와 Wrapsody eCo 문서 공유 앱을 제품 모듈로 분리하고, Outlook 초기화·메일 컨텍스트·Graph API 프록시·고객사별 암호화 설정을 공통화했습니다.
- **성과:** Mind-SAT에서 만든 공통 M365·Graph 연동 모듈을 Wrapsody eCo에 재사용해 추가 앱 개발 기간을 기존 대비 절반으로 줄였습니다. 고객사마다 별도 Add-in 서버를 두지 않고 하나의 멀티테넌트 프록시로 여러 제품을 지원했으며, eCo Add-in을 24개 고객사·273명 운영 환경에 제공했습니다.

### 사내 업무 시스템·ERP 데이터 연동 | Fasoo | 2024

- **역할·기술:** Fullstack Engineer로 인사 관리·품의/결재·고객 관리 시스템을 ASP.NET WebForms에서 React·C#·ASP.NET Core·MSSQL 기반 구조로 마이그레이션했습니다.
- 업무 단위 백엔드 API를 개발하고, 복잡한 조회는 인덱스·DB view·임시 테이블·페이지 단위 조회로 정리했습니다. 인사·재무 ERP를 원천 데이터로 두고 변경분을 주기적으로 반영하는 MSSQL 스케줄러도 개발했습니다.
- **성과:** 화면·API·데이터 처리 책임을 분리해 레거시 시스템의 변경 범위를 줄였습니다. 수동 쿼리로 처리하던 ERP 기준 데이터 반영을 재실행 가능한 스케줄러 작업으로 전환하고, 변경분 insert/update와 검증 쿼리를 통해 반복 작업과 반영 누락 가능성을 낮췄습니다.
