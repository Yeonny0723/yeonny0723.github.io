# AI 엔지니어 경력기술서

Fasoo에서 기업용 보안 제품의 AI 기능과 운영 환경을 개발했습니다. Wrapsody는 기업 문서를 암호화하고 문서별 권한과 버전을 관리하는 서비스로, 약 100만 건의 문서를 약 10여 고객사에 클라우드·온프레미스 형태로 제공합니다. 고객사별 서버 환경, 복잡한 문서 접근 권한, 문서 암·복호화와 종단 간 암호화를 고려해야 하며, 축적된 문서·권한 정보는 검색·요약·질의응답·문서 생성으로 확장할 수 있습니다.

Wrapsody eCo는 암호화된 문서를 사내외 구성원이 Outlook에서 안전하게 공유·협업하도록 연결하는 서비스입니다. Mind-SAT은 약 41개 고객사가 사용하는 피싱 훈련·보안교육 SaaS로, 고객사별 훈련 결과·신고·교육 이력을 관리하고 퀴즈·동영상 교육을 제공합니다. 훈련 메일 분석, 공격 유형 파악, 메일 템플릿·퀴즈 생성에 AI를 활용합니다.

### Wrapsody 문서 생성 Agent | Fasoo | 2026~현재

- **역할·기술:** 메인 개발자로 Python 기반 비동기 문서 생성 기능과 LLM 처리 흐름을 설계·구현했습니다.
- 템플릿과 원천 파일로 DOCX·PPTX·XLSX를 생성하고, LLM 출력은 직접 정의한 문서 연산 문법으로 제한했습니다. 요청 등록과 처리를 분리해 상태 조회와 결과 확인을 지원했습니다.
- **성과:** 기능 구현 후 내부 검증·QA를 진행했습니다. 약 20건의 내부 데이터 비교에서 생성 시간 4~5분→1~2분, 평균 비용 약 350원→100원, 필수 슬롯 누락률 약 20%→2%를 관찰했습니다.

### Mind-SAT AI 콘텐츠 생성·서버 운영 | Fasoo | 2026

- **역할·기술:** 4인 개발팀에서 Python, OpenAI SDK, LangChain 기반 훈련 메일·보안 퀴즈 생성 백엔드를 개발했습니다.
- 산업군·부서·직급·위협 수준과 메일 유형을 생성 조건으로 구성하고, 결과 검토 흐름을 프론트엔드와 연결했습니다.
- **성과:** OCI 단일 AI 서버를 2대 인스턴스 풀과 Private Load Balancer로 전환했습니다. TEST에서 1대 장애 시 신규 요청 무중단과 자동 보충을 검증하고 PROD 전환을 완료했습니다.

### Wrapsody AI 검색·응답 평가 | Fasoo | 2026~현재

- **역할·기술:** 검색·평가 지원 역할로 Playwright를 이용한 반복 평가와 RAG·Text2SQL 품질 검증에 참여했습니다.
- 다국어·동의어·다의어 질의를 분석하고, 기대 문서와 본문 위치를 정의한 36개 평가셋을 구성했습니다.
- **성과:** Text2SQL, 문서 검색, 최종 응답을 단계별로 비교해 모델 변경 전후의 품질 차이와 실패 지점을 추적할 수 있게 했습니다.

### 디자인 시스템 MCP·관련 풀스택 개발 | Fasoo | 2024~2026

- **역할·기술:** React·TypeScript 기반 제품·사내 시스템을 개발하고, 2026년에는 디자인 시스템 조회용 MCP 서버를 개발했습니다.
- 컴포넌트·훅·토큰·Storybook 예제를 구조화해 AI 개발 도구가 실제 UI 규칙을 조회하도록 했습니다. 앞서 사내 공통 UI 라이브러리와 제품 공통 디자인 시스템을 구축했습니다.
- **성과:** 공통 UI를 약 6개 사내 시스템에, 제품 디자인 시스템을 3개 제품에 적용했습니다. MCP로 컴포넌트 50여 개, 훅 20여 개와 아이콘·컬러 100여 개를 조회할 수 있게 했습니다.

### TypeScript 기반 제품·플랫폼 개발 | Fasoo | 2024~2025

- **역할·기술:** React·TypeScript, Node.js·Express, ASP.NET Core, MSSQL을 사용해 M365 Web Add-in과 사내 업무 시스템을 개발했습니다.
- 제품 API·M365 연동·고객사 설정을 분리하고, 레거시 업무 시스템을 React 기반으로 전환해 AI 기능을 연결할 수 있는 제품 개발 기반을 넓혔습니다.
- **성과:** Wrapsody eCo와 Mind-SAT을 새 Outlook에서 제공하는 멀티테넌트 기반과, 업무 데이터의 화면·API·동기화 흐름을 구축했습니다.
