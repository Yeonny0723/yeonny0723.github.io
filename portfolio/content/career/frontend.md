# 프론트엔드 엔지니어 경력기술서

Fasoo에서 권한과 보안 요구가 높은 기업용 제품의 화면과 개발 기반을 만들었습니다. Wrapsody는 기업 문서를 암호화하고 문서별 권한과 버전을 관리하는 서비스입니다. 사내 운영 환경에만 약 100만 건의 문서가 축적돼 있으며, 약 10여 고객사에 클라우드·온프레미스 형태로 제공하고 있습니다. 고객사별 서버 환경과 복잡한 문서 접근 권한, 문서 암·복호화와 종단 간 암호화를 고려해야 하는 제품입니다.

Wrapsody eCo는 암호화된 문서를 웹·클라이언트·Outlook Add-in·모바일에서 사내외 구성원이 안전하게 공유하고 협업하는 서비스입니다. Mind-SAT은 약 41개 고객사가 이용하는 피싱 훈련·보안교육 SaaS로, 훈련 결과·신고·교육 이력을 관리하고 위반자에게 퀴즈와 동영상 교육을 제공합니다. 메일 분석·공격 유형 파악·템플릿 및 퀴즈 생성에 AI를 활용하며, 세 제품 모두 권한 제어와 안전한 사용자 흐름이 중요한 환경입니다.

### Mind-SAT 보안교육 제품 | Fasoo | 2025~2026

- **역할·기술:** 4인 개발팀에서 React·TypeScript로 2.3~2.8 기능 범위의 약 100개 화면과 Python·OpenAI SDK·LangChain 기반 퀴즈 생성 백엔드를 개발하고, AI 서버 고가용성 인프라를 관리했습니다.
- OTP/MFA, 권한별 화면, 동영상 학습, 퀴즈, 관리자 통계를 훈련 이후 교육 이수 흐름으로 연결하고, 훈련 메일과 외부 리소스를 안전하게 표시하는 콘텐츠 보안 경계를 설계했습니다.
- AI 훈련 메일·퀴즈·템플릿 생성 결과의 상태 조회·미리보기·수동 리뷰 UI를 연결해 AI 기능을 실제 제품 흐름에 통합했습니다.
- **성과:** 2026년 6월 기준 41개 고객사·19,790명이 사용하는 서비스의 교육·관리자 기능과 콘텐츠 표시 보안 경계를 구축했습니다. OCI Instance Pool·Private Load Balancer·이미지 인스턴스 빌더로 무중단 배포와 장애 복구가 가능한 AI 서버 운영 구조를 만들었습니다.

### M365·Outlook Web Add-in | Fasoo · Wrapsody eCo·Mind-SAT | 2025

- **역할·기술:** 2인 협업으로 C#/.NET Outlook 클라이언트를 React·TypeScript·Office.js 기반 M365 Web Add-in으로 전환했습니다.
- 공통 M365 연동과 제품별 기능을 모노레포에서 분리하고, 메일·인증·Microsoft Graph 연동 및 고객사별 테넌트 설정을 구성했습니다.
- **성과:** 새 Outlook에서 eCo 문서 공유와 Mind-SAT 메일 신고를 제공했습니다. Mind-SAT에서 만든 공통 M365·Graph 연동 모듈을 재사용해 Wrapsody eCo Add-in의 추가 개발 기간을 기존 대비 절반으로 줄였고, eCo Add-in을 24개 고객사·273명 운영 환경에 제공했습니다.

### 공통 디자인 시스템·MCP | Fasoo | 2024~2026

- **역할·기술:** React·TypeScript 공통 UI 라이브러리와 제품 디자인 시스템을 개발하고, AI 도구가 이를 조회하는 MCP 서버를 구현했습니다.
- 컴포넌트 API·디자인 토큰·접근성 규칙을 정리하고 Storybook 예제와 소스 정보를 MCP 조회 데이터로 만들었습니다.
- **성과:** 공통 UI를 약 6개 사내 시스템에, 제품 디자인 시스템을 3개 제품에 적용했습니다. 프론트엔드 엔지니어 4명이 MCP를 사용하고 있으며, LLM Agent에 UI 개발을 맡긴 뒤 수동으로 검토·수정하는 시간을 기존의 1/5로 줄였습니다.

### 성능·E2E·CI/CD | Fasoo · Mind-SAT 및 프론트엔드 서비스 | 2025~2026

- **역할·기술:** React 화면 성능 개선과 Playwright E2E, Jenkins 기반 검증·배포 흐름을 담당했습니다.
- 대량 신고 이력에는 가상화, 초기 로딩에는 코드 분할을 적용했습니다. 피싱 훈련·퀴즈·라이선스·권한별 접근을 외부 메일과 백엔드 연동까지 검증했습니다.
- **성과:** 핵심 운영 시나리오 4종의 수동 검증 시간을 약 30분에서 E2E 약 8분으로 줄이고, 배포 버전과 산출물을 Jenkins 작업에서 추적할 수 있게 했습니다.

### 사내 업무 시스템·ERP 데이터 연동 | Fasoo | 2024

- **역할·기술:** Fullstack Engineer로 인사 관리·품의/결재·고객 관리 시스템을 ASP.NET WebForms에서 React·TypeScript, C#·ASP.NET Core·MSSQL 기반 구조로 마이그레이션했습니다.
- 사용자 설문과 기존 업무 흐름을 바탕으로 화면과 백엔드 API를 다시 구성하고, MSSQL 인덱스·DB view·임시 테이블·페이지 단위 조회로 목록과 집계 쿼리를 개선했습니다. 인사·재무 ERP 데이터를 주기적으로 반영하는 MSSQL 스케줄러도 개발했습니다.
- **성과:** 화면·API·데이터 처리 책임을 분리해 레거시 시스템의 변경 범위를 줄였습니다. 수동 쿼리로 처리하던 ERP 기준 데이터 반영을 재실행 가능한 스케줄러 작업으로 전환하고, 변경분 insert/update와 검증 쿼리를 통해 반복 작업과 반영 누락 가능성을 낮췄습니다.
