# 프론트엔드 엔지니어 경력기술서

Fasoo에서 권한과 보안 요구가 높은 기업용 제품의 화면과 개발 기반을 만들었습니다. Wrapsody는 기업 문서를 암호화하고 문서별 권한과 버전을 관리하는 서비스로, 약 100만 건의 문서를 약 10여 고객사에 클라우드·온프레미스 형태로 제공합니다. 고객사별 서버 환경과 복잡한 문서 접근 권한, 문서 암·복호화와 종단 간 암호화를 고려해야 하는 제품입니다.

Wrapsody eCo는 암호화된 문서를 사내외 구성원이 Outlook에서 안전하게 공유·협업하도록 확장한 서비스입니다. Mind-SAT은 약 41개 고객사가 이용하는 피싱 훈련·보안교육 SaaS로, 훈련 결과·신고·교육 이력을 관리하고 위반자에게 퀴즈와 동영상 교육을 제공합니다. 메일 분석·공격 유형 파악·템플릿 및 퀴즈 생성에 AI를 활용하며, 세 제품 모두 권한 제어와 안전한 사용자 흐름이 중요한 환경입니다.

### Mind-SAT 보안교육 제품 | Fasoo | 2025~2026

- **역할·기술:** 4인 개발팀에서 React·TypeScript로 2.3~2.8 기능 범위의 약 100개 화면 개발에 참여했습니다.
- OTP/MFA, 권한별 화면, 동영상 학습, 퀴즈, 관리자 통계를 훈련 이후 교육 이수 흐름으로 연결하고, 훈련 메일과 외부 리소스를 안전하게 표시하는 콘텐츠 보안 경계를 설계했습니다.
- AI 훈련 메일·퀴즈·템플릿 생성 결과의 상태 조회·미리보기·수동 리뷰 UI를 연결해 AI 기능을 실제 제품 흐름에 통합했습니다.
- **성과:** 2026년 6월 기준 41개 고객사·19,790명이 사용하는 서비스의 교육·관리자 기능과 콘텐츠 표시 보안 경계를 구축했습니다.

### M365·Outlook Web Add-in | Fasoo · Wrapsody eCo·Mind-SAT | 2025

- **역할·기술:** 2인 협업으로 C#/.NET Outlook 클라이언트를 React·TypeScript·Office.js 기반 M365 Web Add-in으로 전환했습니다.
- 공통 M365 연동과 제품별 기능을 모노레포에서 분리하고, 메일·인증·Microsoft Graph 연동 및 고객사별 테넌트 설정을 구성했습니다.
- **성과:** 새 Outlook에서 eCo 문서 공유와 Mind-SAT 메일 신고를 제공하고, 제품 기능과 고객사 설정을 독립적으로 변경할 수 있는 기반을 마련했습니다.

### 공통 디자인 시스템·MCP | Fasoo | 2024~2026

- **역할·기술:** React·TypeScript 공통 UI 라이브러리와 제품 디자인 시스템을 개발하고, AI 도구가 이를 조회하는 MCP 서버를 구현했습니다.
- 컴포넌트 API·디자인 토큰·접근성 규칙을 정리하고 Storybook 예제와 소스 정보를 MCP 조회 데이터로 만들었습니다.
- **성과:** 공통 UI를 약 6개 사내 시스템에, 제품 디자인 시스템을 3개 제품에 적용했습니다. AI 도구가 기존 컴포넌트와 사용 규칙을 확인할 수 있게 했습니다.

### 성능·E2E·CI/CD | Fasoo · Mind-SAT 및 프론트엔드 서비스 | 2025~2026

- **역할·기술:** React 화면 성능 개선과 Playwright E2E, Jenkins 기반 검증·배포 흐름을 담당했습니다.
- 대량 신고 이력에는 가상화, 초기 로딩에는 코드 분할을 적용했습니다. 피싱 훈련·퀴즈·라이선스·권한별 접근을 외부 메일과 백엔드 연동까지 검증했습니다.
- **성과:** 핵심 운영 시나리오 4종의 수동 검증 시간을 약 30분에서 E2E 약 8분으로 줄이고, 배포 버전과 산출물을 Jenkins 작업에서 추적할 수 있게 했습니다.

### React 풀스택 전환 | Fasoo · 사내 업무 시스템 | 2024

- **역할·기술:** 인사·결재·고객 관리 시스템의 화면과 API를 React·TypeScript, ASP.NET Core, MSSQL 기반으로 개발했습니다.
- 기존 WebForms 업무 흐름과 사용자 설문을 반영해 화면·API를 재구성하고, 목록 조회와 데이터 동기화 흐름을 정리했습니다.
- **성과:** 사내 업무 시스템을 신규 웹 구조로 전환하고, 공통 UI와 GitLab CI/CD를 적용해 반복 개발·수동 배포 작업을 줄였습니다.
