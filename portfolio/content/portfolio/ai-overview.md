# AI Application Engineer 포트폴리오

보안 제품에 LLM 기능을 넣고, 결과를 평가할 수 있고 실패해도 복구되는 형태로 운영해 왔습니다. AI에게 맡길 일과 코드·규칙이 책임질 일을 먼저 나누고, 모델과 설계는 평가셋과 비용으로 결정합니다.

이 페이지는 구조도와 공개 코드로 보여주는 데 집중했습니다. 프로젝트별 판단 과정은 [경력기술서](/career-description/ai-engineer)에 자세히 적었습니다. 회사 시스템 구조도는 보안상 실제 호스트·포트·네트워크 정보를 빼고 역할 단위로 일반화했습니다.

| 프로젝트 | 한 줄 결과 |
| --- | --- |
| Wrapsody 문서 생성 | 청킹 도입으로 추론 성공률 약 20% 향상, 모델 비교로 비용 약 1/10 |
| Wrapsody 품질 평가 | 단계별 회귀 평가로 실패 지점을 찾아 정답 20/36 → 36/36 |
| Mind-SAT AI | 악성 메일을 직접 검사하던 과정을 OCR로 대체, AI 서버 장애 복구 1분 이내 |
| 디자인 시스템 MCP | 소스에서 자동 컴파일되는 레지스트리로 AI가 기존 컴포넌트를 재사용 |
| agent-orchestration | AI 코딩 에이전트와 일할 때 쌓이는 이해의 부채를 줄이는 개발 워크플로 |
