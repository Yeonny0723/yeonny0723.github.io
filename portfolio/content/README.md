# 커리어 문서 콘텐츠

이 폴더의 Markdown을 수정하면 커리어 문서가 바뀝니다. 화면에서 Resume, Career Description, Portfolio를 선택하고 AI Engineer 또는 Frontend Engineer 포지션별 문서를 확인할 수 있습니다.

## 파일 구조

| 경로 | 역할 |
|---|---|
| `profile.md` | 이름·연락처·공통 소개 |
| `positioning.md` | 포트폴리오 공통 포지셔닝 |
| `resume/ai.md` | AI Engineer 이력서 |
| `resume/frontend.md` | Frontend Engineer 이력서 |
| `career/ai.md` | AI Engineer 경력기술서 |
| `career/frontend.md` | Frontend Engineer 경력기술서 |
| `portfolio/*.md` | 제품 개발 방식과 프로젝트 사례 |
| `skills.md` | 기술 역량 |
| `education.md` | 학력 |
| `certifications.md` | 자격증 |
| `activities.md` | 교육·커뮤니티 활동 |
| `links.md` | 외부 링크 |

## 작성 원칙

- `소스/experiences/`에 있는 사실·역할·결과를 기준으로 쓴다.
- 경험은 문제 → 제약 → 선택지 → 판단 → 구현 → 결과 순서로 정리한다.
- 수치와 기술을 새로 만들지 않는다.
- 제품 보안 기능과 개발 생산성·보안 거버넌스 도구를 구분한다.
- AI 평가 경험에서 Golden Dataset·검색·RAG·Text2SQL은 하나의 평가 체계로 설명한다.
